## HOW TO FIX - COMPLETE STEPS:

### Step 1: Uninstall Old App
```
Android Studio:
1. Run → Run 'app'
2. Wait for app to launch
3. Then in terminal: adb uninstall com.aizaya.app

OR manually on device:
Settings → Apps → AI ZAYA → Uninstall
```

### Step 2: Clean Gradle Cache
```
In Android Studio:
1. File → Invalidate Caches
2. Select "Invalidate and Restart"
3. Wait for Android Studio to restart
```

### Step 3: Clean & Rebuild
```
In Android Studio:
1. Build → Clean Project
2. Build → Rebuild Project
3. Wait for build to complete (may take 2-5 minutes)
```

### Step 4: Fresh Install
```
In Android Studio:
1. Run → Run 'app'
2. OR: Run → Edit Configurations → uncheck "Run"  then check it
3. Wait for fresh install to device
```

### Step 5: Test
```
1. Open AI Chat
2. Send: "Hello"
3. Wait 5-10 seconds
4. Should see: AI response (NOT error)
```
